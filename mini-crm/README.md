# Mini CRM

Angular forma įmonės ir vieno ar daugiau kontaktinių asmenų duomenims įvesti. Kiekvieno kontakto visi laukai yra privalomi. Paspaudus „Registruotis“, galiojantys duomenys išvedami į naršyklės konsolę; jie nėra išsaugomi.

```bash
npm install
npm start
```

Atidarykite http://localhost:4200/. Produkcijos versija: `npm run build`.

Pagrindiniame puslapyje pateikiama būsimo įmonių sąrašo vieta, o registracijos forma pasiekiama per „Nauja įmonė“. Navigacija, įmonių sąrašo ir registracijos komponentai bei maršrutai yra atskirti `src/app` kataloge.
